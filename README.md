# ⚡ NEON ROBOT ARENA

Offline neon robot survival game for Android. Automatic aiming, waves, upgrades, high scores, touch joystick. No internet permission, no account, no ads.

**APK download:** open [Actions](../../actions/workflows/build-apk.yml), select the latest successful run, and download `Neon-Robot-Arena-APK` under Artifacts.

Build locally: `gradle assembleDebug` with JDK 17 and Android SDK 35.
